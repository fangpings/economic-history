# 第25章 广场协议与日本的政策选择

[返回目录](README.md)

1985年9月22日，五国财政部长和中央银行行长在纽约广场饭店达成政策协调声明。这一事件后来常被当成日本命运的分界线：美国要求日元升值，日本被迫降息，泡沫破裂，长期停滞。这条直线把若干确实发生的事件连在一起，却省略了最需要解释的部分：为什么美元先前那么强，日元升值如何改变不同企业的利润，日本当局具体选择了什么，为什么1987年的协调目标已经与1985年不同，以及相同的外部压力为何不必然产生同样的资产泡沫。

本章先把汇率协调和国内政策选择讲清。土地抵押、股票融资、银行竞争与资产价格的互相放大留到下一章；泡沫破裂后的坏账识别和处置则留到第27章。读完应当能判断一项国际协议究竟规定了什么，也能把它与随后各国自主作出的政策选择分开。

## 一、美元升值为什么会成为政治问题

先回到美国反通胀的后果。1980年代初，美国货币紧缩提高美元融资成本，随后经济复苏又带动支出和进口。外国投资者愿意持有美元资产，可以为美国吸收国外资金提供条件；但资本流入推动的汇率变化，会改变本国产业面对的价格。美元越强，美国居民用同样工资越容易购买某些外国商品，美国工厂按美元支付工资和成本，却越难在国外保持低价。消费者、进口商和出口工人对“强美元”的感受因此不必一致。

Gagnon对工业国汇率调整的研究，将1980年底至1985年初美元升值与紧货币、松财政的组合联系起来，同时提醒：1982年以后利差的变化已不能简单解释升值继续，投资环境和升值预期也可能重要。他把后期的一部分走势解释为可能带有泡沫成分。这是研究判断，不是证明美元每一次上涨都由某一政策单独决定。[Gagnon，2009年研究，美国案例及注23](https://www.federalreserve.gov/pubs/ifdp/2009/966/ifdp966.htm)

这里的财政货币组合可以用一条具体链条理解。政府减税或扩大支出，若没有相应增加其他收入，就需要更多融资；私人消费和投资也可能受到支持。在其他条件一定时，国内总支出超过本国收入的一部分，表现为从国外净购买商品服务并吸收外部融资。较高的预期回报可以吸引投资者，但投资者还要判断美元未来价格，并非只比较当日存款利率。美元升值又使进口更有吸引力、出口更难扩张，外部逆差因而可能持续。

“吸收外部融资”并不是美国居民把每一件进口商品都直接用国债结账。进口商支付、外国出口商存放美元、银行调整资产、国际投资者购买证券，是相互连接但由不同主体执行的交易。国际收支的对应关系说明融资必须有人持有，不直接告诉我们谁先发起、为什么愿意持有，更不能由一个恒等式证明全部逆差都是外国贸易壁垒造成。

这种分配矛盾很容易进入政治。对消费者，便宜进口带来可见利益；对某个产业集中的城市，失去的订单和岗位可能高度集中。政府可以把回应放在汇率、财政、贸易规则、产业调整或劳动者支持上，不同工具帮助的人和时间不同。提高关税能改变具体商品价格，却不保证国家总储蓄与总投资的关系因此自动重平衡；降低美元也不能立刻创造国外客户、供应链和新增出口产能。

所以，理解广场协议的起点不是“某一国增长太快需要被打压”，而是大国之间的外部失衡、国内产业压力与政策组合已经难以彼此兼容。日本是美国贸易摩擦的重要对象，西德等其他顺差经济体也在协调范围之内。协议是多国处理这一矛盾的一次尝试，不能只按一份美日双边命令来阅读。

## 二、1985年秋：汇率谈判与贸易压力同时推进

1985年9月23日，也就是广场会议次日，里根在白宫向工商与贸易界发表讲话。一方面，他为开放贸易辩护；另一方面，宣布强化处理被美方认为不公平的贸易做法，包括日本烟草市场的调查，以及加快皮革和皮鞋限制争端处理。他还要求给日本特定产品市场开放谈判设置时间压力，并明确提到自己授权财政部长詹姆斯·贝克参与前一天的协调。[里根1985年9月23日工商贸易界讲话](https://www.reaganlibrary.gov/archives/speech/remarks-white-house-meeting-business-and-trade-leaders)

这个具体场景说明，汇率协调没有替代所有贸易政策。政府希望减轻保护主义压力，同时仍在逐项争取市场开放。日本企业也不会因为日元升值，就自动获得任何海外市场不受限制的保证。汇率是宏观相对价格，烟草、皮革或政府采购规则则涉及具体进入条件；两者可同时影响贸易，但不能互相冒充。

从日本方面看，保持美国市场开放本身就是利益。日本外务省在1987年外交蓝皮书的美日关系部分，既强调本国扩大内需和结构调整，也记录日方要求美国减少财政赤字、改善竞争力。这份材料体现日本政府的谈判立场：两国都有需要调整的结构，不能只靠日本限制出口或单独修改汇率解决。[日本外务省《1987年外交蓝皮书》，北美经济关系部分](https://www.mofa.go.jp/policy/other/bluebook/1987/1987-3-3.htm)

这里应把利益不对称与完全没有选择区分开。美国市场、美元地位和贸易措施使美方拥有重要压力工具；日本则有顺差、产业能力和本国政策执行权。日本政府可能为了维护较大的贸易关系接受某些代价，也可能真心希望以更强日元和金融开放改善本国经济结构。接受协议不证明其后每一次降息都毫无国内理由，也不证明任何代价都是日本当局早已准确预见并自愿选择的。

## 三、带读广场声明：它没有写一个日元永久目标价

9月22日声明的参与方是美国、日本、西德、法国和英国的财政部长与央行行长。核心结论认为主要非美元货币对美元进一步有序升值是合意的，各方准备加强合作；声明同时把外部失衡与保护主义压力联系起来。日本所列意向包括注意日元汇率的灵活货币政策、金融市场开放，以及通过消费和住房信用市场支持私人需求。财政部分仍包含减少中央政府赤字的目标。[广场声明，第10—18段及日本政策意向](https://g7.utoronto.ca/finance/fm850922.htm)

读者应先问：这是一份什么性质的文件？它是财长和央行行长的协调声明，列出政策方向和各国意向；它不是重新建立美元黄金兑换的国际货币章程，也不是给居民保证某一日元价格的兑换合同。公开文本没有写日元必须永远停在每美元多少日元，更没有列出几年之后日本土地应该值多少钱。

第二个问题是：“有序升值”与“不惜代价升值”是否相同？不同。前者包含速度和市场秩序的考虑。若汇率调整极快，企业已签合同可能来不及重新报价；若当局只维持口头态度而实际政策完全相反，市场也可能怀疑承诺。协调的难点，正在于汇率、内需、物价和政治承受力不能同时靠一句话确定。

第三个问题是：扩大信用是否已经规定后来必须形成泡沫？声明的日本意向确实把消费和住房信用列为内需渠道，这是值得重视的制度接口；但贷款条件、银行资本、土地抵押估值、监管力度和投资者预期没有由这句话自动决定。同样，保留财政整顿目标意味着政策组合受到约束，不能把广场后的日本简单写成从此所有政府支出无条件扩张。

我们可以把文件直接支持的结论，与需要进一步证明的结论分开：前者是五国希望美元调整，并作出协调和各国政策承诺；后者是干预究竟贡献多少、汇率变化幅度是否适当、日本内需措施如何落实以及泡沫为什么形成。后者必须继续读操作记录、国内政策和数据，不能让一份声明承担整整十五年的因果解释。

## 四、先看汇率路径：日元升值早于会议，也没有在会议后立刻到终点

下面使用美联储经FRED提供的同一条月均汇率序列。报价为每1美元可兑换多少日元，数字下降表示美元对日元贬值、日元对美元升值。

| 月份 | 日元/美元，月均，四舍五入至两位 |
| --- | ---: |
| 1985年2月 | 260.48 |
| 1985年8月 | 237.46 |
| 1985年10月 | 214.68 |
| 1986年9月 | 154.73 |
| 1987年2月 | 153.41 |
| 1987年12月 | 128.24 |

来源：[美联储EXJPUS月度序列](https://fred.stlouisfed.org/data/EXJPUS)。9月会议不能用9月整月平均充当会议前一日价格，因此这里另列8月和10月观察前后走势，不把月均数据误写为即时反应。

这条路径至少说明两点。第一，2月至8月已经出现明显变化，广场不是美元在这轮周期中第一次下跌的起点。第二，1986和1987年还发生了大量变化，不能把所有幅度都解释成会议当晚一次定价。John Taylor在其协议三十年后的研究中也指出，会前数月美元已经走弱，并讨论政策变化与外汇干预效果难以分离的问题。关于干预的竞争解释，后文再展开。[Taylor，2015年研究，第3页](https://kingcenter.stanford.edu/sites/g/files/sbiybj16611/files/media/file/559wp_0.pdf)

“升值了多少”还取决于分母。用教学整数比较，每美元从240日元变成160日元，美元以日元表示的价格下降三分之一；但每日元可买到的美元从1/240增至1/160，日元的美元价值增加50%。这不是两组互相冲突的数据，而是倒数报价的百分比不对称。如果把日元升值50%误写成每美元日元数下降50%，企业账就会算错。

另一个不能忽略的区别是双边名义汇率与实际竞争力。日本企业与美国、欧洲和亚洲企业竞争，投入可能来自多国；工资、生产率和本地价格也会变化。美元日元汇率能告诉我们合同换算，却不能独自衡量日本全部出口的实际竞争力。后面先从一家企业的现金账入手，再回到政府为何担心汇率变化过快。
## 五、出口商的利润账：升值不会平均作用于所有日本人

日本外务省同期蓝皮书把快速日元升值描述为出口导向企业遭遇的严重冲击，并记录日方在1986年10月、1987年1月的美日财长会谈及1987年2月多国协调中争取汇率稳定。这是政府当时对问题的判断，不能据此推断日本每个行业收入都下降，但它说明政策关注点为什么从促进调整转向担心调整过快。[《1987年外交蓝皮书》，国际货币形势第1部分](https://www.mofa.go.jp/policy/other/bluebook/1987/1987-4-4.htm)

假设一家日本设备商与美国客户签下每台1万美元的合同，生产一台设备需要180万日元成本，暂且没有外汇套期保值。每美元240日元时，收到美元可换240万日元，毛收益为60万；每美元160日元时，只换到160万，若成本不变，就亏20万。设备本身没有突然变差，美元售价也没有变化，但以日元支付的工资、厂房和零件成本不会同步降低三分之一。

| 教学情形，单位万日元/台 | 每美元240日元 | 每美元160日元 |
| --- | ---: | ---: |
| 固定美元售价折成日元 | 240 | 160 |
| 暂定全部日元成本 | −180 | −180 |
| 简化毛收益 | **60** | **−20** |

企业有多种应对，但每一种都有约束。若要在新汇率下维持240万日元收入，美元售价必须提高到1.5万美元，涨价50%；美国客户可能转买别家。若仍卖1万美元，企业可以降低成本或接受利润减少，但工资合同、厂房和供应关系无法当天全部重写。若从海外购入零件，升值也会降低该部分日元成本，因此净损失取决于投入结构。

把后一点写进账里：假设原180万成本中，120万是日元成本，另60万是按2500美元购入的零件。在240日元汇率下仍是180万；汇率到160时，美元零件只需40万，总成本降到160万。企业这时恰好不赚不亏，而非亏20万。出口收入的汇兑损失被进口成本部分抵销。这两个案例之间的差别，就足以说明为什么不能把所有出口企业当成同一资产负债表。

已签远期合约的企业，又可能暂时按旧价格换汇，但保护通常有金额和期限限制。远期把风险交给承担另一端义务的交易对手，不会替整个国家取消升值；等合约到期，下一批订单仍面对新条件。大型企业可以增加海外生产，以当地收入匹配当地成本；小型供应商可能难以迁移，反而承受上游压价和订单波动。产业调整所需时间，正是当局担心升值过快的原因之一。

另一方面，进口能源、原料和外国商品的日元成本下降，居民出境购买力上升，持有外币负债者的日元偿付负担也可能减少。持有美元资产却以日元生活的投资者，则承受折算损失。判断升值的社会效果，需要追踪收入币种、成本币种和持仓，不能把出口行业困难直接等同于所有居民福利恶化。

## 六、日银没有在广场之后立即开始连续降息

后来泡沫的结果容易让人误以为1985年9月之后日银只做了一件事：不断压低利率。但档案研究记录的初期动作恰好更复杂。1985年10月下旬至12月中旬，日银为消除降息预期、支持日元较强走势，让短期市场资金紧张反映到利率。三个月票据月均利率从9月6.37%升至11月7.86%；12月下旬才逐步恢复较中性的市场操作。这不是官方贴现率的同幅上调，而是市场利率操作。[Itoh、Koike与Shizume，2015年档案研究，印刷第126—127页](https://www.imes.boj.or.jp/research/papers/english/me33-5.pdf)

这一段时序很重要。起初，较高日本短期利率可以支持日元，符合调整美元偏强格局的方向；但如果企业利润和投资已因升值受压，较紧国内融资条件又会增加困难。政策目标不是天然一致的。随着汇率显著变化，继续优先促升值的国内代价变得更突出，政策重心也有理由改变。是否改变得及时、后来宽松维持是否过久，是两个可以分开评价的问题。

从1986年1月起，官方贴现率才进入这轮五次下降。官方贴现率是央行特定放款的价格，也是当时重要的政策信号；它不是所有企业银行贷款合同的统一利率，更不能与三个月票据或无担保隔夜拆借的市场报价任意拼接。

| 生效日 | 官方贴现率变化 |
| --- | --- |
| 1986年1月30日 | 5.0% → 4.5% |
| 1986年3月10日 | 4.5% → 4.0% |
| 1986年4月21日 | 4.0% → 3.5% |
| 1986年11月1日 | 3.5% → 3.0% |
| 1987年2月23日 | 3.0% → 2.5% |

来源：[翁邦雄、白川方明、白塚重典，2001年研究，表2](https://www.imes.boj.or.jp/research/papers/english/me19-s1-14.pdf)。这里严格列生效日；日本银行原公告目录中最后一次议长谈日期为2月20日，不能把2月23日反称为首次宣布日。[日银1995年以前政策公告目录](https://www.boj.or.jp/mopo/mpmdeci/mpr_before1995/index.htm)

降息怎样帮助受压经济？对需要周转的企业，融资成本下降可以提供缓冲；对家庭，较低借款成本可以支持住房和消费；对本来收益接近融资门槛的投资项目，也可能使计划变得可行。若新的国内需求增加进口或吸收原本面向出口的产能，对外顺差也可能减小。因此，这套工具同时服务于缓解升值冲击与扩大内需，并非只能解释为某个外部政府的命令。

但工具不会只流向受损出口商。拥有土地、证券或担保优势的借款人也能受益；较低贴现率可能提高各种远期现金流的估值。若银行认为抵押品还会升值，信用扩张就可能进入既有资产交易，而不全是新增设备和住房服务。为什么这条分支后来特别强，需要下一章的银行和资产制度解释。仅凭降息发生，尚不足以证明其后贷款的部门分配已经注定。

## 七、前川报告与“内需”：结构调整不只是把利率降下来

中曾根康弘政府在1985年10月组织由前日银总裁前川春雄主持的咨询小组，1986年4月提交报告。报告把逐步降低对外失衡、转向国内需求带动增长，与贸易产业结构、汇率、金融开放及储蓄税制的改变放在一起。它是政策建议和方向，不是一份所有措施已经完成的执行清单。[2015年档案研究，前川报告附录，印刷第190页](https://www.imes.boj.or.jp/research/papers/english/me33-5.pdf)

“内需主导”需要拆成可操作问题。居民是否愿意和能够消费，取决于收入、公共保障、住房成本和预期；企业是否投资，取决于未来产品需求和资本回报；政府是否提供基础设施，受预算、项目质量和地方执行制约。利率下降能影响其中一些价格，却不能自动完成全部制度调整。若住房信贷增加主要推高现有土地价格，居民为同样居住空间支付更多，资产繁荣与生活改善就未必同步。

前川报告的另一个意义，是把顺差问题从“出口商太能干”转向国内资源使用的整体安排。国民储蓄超过国内投资的一部分，对应对外净借出。这个关系并不意味着应强迫每一个家庭花掉储蓄，而是让政策比较不同调整方式：更有价值的国内投资、改善居民消费条件、金融渠道变化，以及外国需求和本国财政之间如何配合。对于以银行存款和企业内部资金为重要融资来源的经济体，储蓄行为改变还会影响金融机构，而不只是购物数量。

也不能把报告直接当成日本自认全部顺差都有问题。顺差是否可持续，需要看人口、投资机会、外部伙伴和资产收益；国际摩擦则还包含双边产业和市场进入争端。报告提出的国际协调目标，带有维护开放贸易关系的政治考虑。评价其经济效果，要再看哪些政策落地、支出在哪里增加，而不是只看一个“结构改革”标签。

## 八、1987年财政方案：六万亿日元不是央行当天撒出的现金

日本在1987年5月决定紧急经济措施，提出超过6万亿日元的方案，7月通过配套追加预算。同期外交蓝皮书将其列为向国内需求带动增长转变的重要行动。它把消费、住房和设备投资变化与政策联系起来，但这种官方效果归因仍须与其他条件分开评估。[《1988年外交蓝皮书》，扩大国内需求部分](https://www.mofa.go.jp/policy/other/bluebook/1988/1988-2-2.htm)

OECD在1989年的日本调查中，把方案概括为约5万亿日元公共投资和约1万亿日元净减税，并说明落实依靠不同渠道：财政投融资、地方政府投资，以及利用NTT股份出售收入的无息贷款等。7月中央追加预算中的新增支出约2.2万亿日元，并不等于方案标题的6万亿全部成为同一笔中央预算支出。[OECD《日本经济调查1989》，注11及财政方案附录](https://www.oecd.org/content/dam/oecd/en/publications/reports/1989/01/oecd-economic-surveys-japan-1989_g1g1713d/eco_surveys-jpn-1989-en.pdf)

这里的财政投融资，是政府运用资金通过贷款和投资等方式支持项目的制度渠道。贷款需要看本金偿还与利息，预算拨款则直接形成不同的财政责任；国有股份出售是资产变现，不等于政府创造了同样规模的新增收入能力。地方投资也要由地方执行和融资。把这些项目加进一份政策方案，是为了展示资源动员规模，但不能把它们一律叫作中央银行印钱。

还要区分提前支出与永久新增。某项工程若本来明年要做，现在提前，会增加今年需求、减少相对明年的空间；若是原本没有的新增工程，跨年影响不同。某笔贷款额度如果无人借用，就没有对应实际投资。因而判断财政刺激力度，理想上应比较没有方案时的支出路径、实际执行和资金来源，而不是只以标题金额除以GDP。

对当时政策选择而言，这个方案提供了货币宽松之外的内需渠道。公共工程可以直接带来订单，减税可以增加居民可支配收入；但施工、招标和家庭消费反应各有时滞。若扩大的是土地或建筑密集型支出，又可能与资产市场相互影响。我们应分别评价需求托底、资源配置和资产价格后果，不能因为某项政策有助于摆脱出口压力，就推断其全部长期效果同样有利。
## 九、卢浮宫协议：1987年已在试图稳住美元

在上一节的1987年财政方案之前，国际协调已经出现方向变化。1987年2月22日发表的卢浮宫声明列出的参与国是加拿大、法国、西德、日本、英国和美国。文件认为广场以来的汇率变化已把主要货币带到大体符合基本面的范围，进一步大幅变化可能损害增长和调整，因而希望围绕当时水平促进稳定。日本承诺以财政货币政策支持内需，并在文件中确认2月23日贴现率下调半个百分点。[卢浮宫声明，参与方、第7及第10段](https://g7.utoronto.ca/finance/fm870222.htm)

声明中的配合并非只有日本降息。美国提出将1988财年赤字降至国民生产总值的2.3%，对照的是当时估计1987财年的3.9%；西德承诺建议扩大已经通过的1988年减税规模。这些是当时的政策承诺和估计，不是后来执行结果。其逻辑是顺差方增加内需、逆差方改善国内失衡，使汇率稳定有国内政策支撑；若各国执行进度或市场判断不同，单靠共同声明就未必能维持目标。

对比两份文本，广场希望主要非美元货币进一步有序升值，卢浮宫则担心继续大幅变动。这不是无关紧要的措辞区别。1985年卖美元、买日元可以服务于最初方向；到了需要阻止日元过快升值的阶段，日方可能要做相反交易。把1985—1989所有干预统一叫作“美国强迫日本一直推高日元”，会把操作方向抹掉。

卢浮宫也没有恢复布雷顿森林式的普遍固定平价和黄金承诺。公开声明对当时基本面的判断，是在各国政策承诺成立条件下作出的；政策执行、市场预期和新的冲击都会改变可维持范围。第四节的数据已经显示，1987年2月至12月美元日元月均报价仍从约153降至128。达成稳定意向，不等于当局能够保证汇率从此不动。

还有一个细节值得保留：日银1987年2月20日已有降息公告，卢浮宫公开声明在22日，降息23日生效。可以说这次行动处于协调过程之中，却不能仅凭23日晚于22日，就写成日银听完声明之后才临时决定。谈判、国内决定、公开宣布和实际执行通常相互交织。认真排日期，有时就足以推翻过分戏剧化的单日故事。

日本同时追求更稳定的日元和更强的内需，形成一种有吸引力却有风险的组合：较低利率有机会减轻升值压力，又能支持国内借款；但若外部汇率仍在变化，政策可能被不断要求再多承担一点任务。国际协调的困难，不是各方不知道稳定的好处，而是每个国家的需求、财政、通胀与资产市场未必在同一阶段。

## 十、外汇干预的账：卖美元和买美元不能写成同一种“放水”

美国财政部对外汇稳定基金的历史说明确认，广场之后发生了协调卖出美元的操作；在从广场到1990年的不同阶段，美国货币当局又分别有净卖出和净买入美元时期。它同时提醒读者，财政部外汇稳定基金的数据与美联储公开市场账户是两个账户，不能只拿其中一方就当作全体美国操作。[美国财政部，外汇稳定基金历史](https://home.treasury.gov/policy-issues/international/exchange-stabilization-fund/exchange-stabilization-fund-history)

实际操作并非五国同时按下一个按钮。纽约联储外汇业务负责人Sam Cross在1985年10月1日向联邦公开市场委员会报告：9月23日东京休市，欧洲先开市，德国央行在法兰克福卖出美元；当天美方卖出7000万美元买日元、7900万美元买马克。9月24日东京重新开市后，企业买美元的需求使美元面临反弹，日银卖出美元加以抵抗。报告所述六个营业日，美方累计卖出4.08亿美元，分别用于买入等值2.24亿美元日元和1.84亿美元马克，联储与财政部各承担一半。[Cross，1985年10月1日FOMC简报，PDF第2—3页](https://www.federalreserve.gov/monetarypolicy/files/FOMC19851001material.pdf)

同一份简报说明，美方通常在美元回升时入市，避免主动把它推入失控下跌；操作还故意保持较高可见度，让市场知道承诺后面有交易。这是当天执行人员的意图说明，并不独立证明预期信号最终贡献了多少汇率变化。我们至少能确定，官方并非只发一段文字，也不是不分价位无限抛售。美元交易以不同机构的账户承担，执行者还要判断市场时段、交易对手和是否追击行情。

先用一个抽象货币当局的教学账看方向，暂把财政和央行结算合并展示。假设当局原有美元资产，按每美元200日元向银行卖出1亿美元、收取200亿日元。资产端美元减少，银行用于付款的本币结算余额减少。若没有其他抵销动作，本币流动性会收缩。它并不是因为发生了“外汇干预”，就必然向国内增加200亿日元。

反过来，当局从银行买入1亿美元并提供200亿日元，外币资产增加，本币结算余额增加。这个方向才有直接扩张本币流动性的可能。两种交易都叫干预，但买卖方向完全相反。上面的真实操作报告区分了美方财政部与联储各自承担的交易；本表只解释合并后的方向，不能将任何国家财政部门持有的外汇资产都改记为央行资产。

| 自拟操作，按每美元200日元 | 当局外币资产 | 银行本币结算余额，未抵销时 |
| --- | ---: | ---: |
| 卖出1亿美元、买入日元 | −1亿美元 | −200亿日元 |
| 买入1亿美元、卖出日元 | +1亿美元 | +200亿日元 |

如果当局希望外汇交易不改变本币市场流动性，就可以安排反向国内操作。例如买入美元增加200亿日元之后，再通过出售本币证券等方式吸收200亿；资产负债表构成改变，但本币结算余额的净变化可以为零。这通常称为冲销干预。反过来，卖出美元回收本币后，购入国内资产也可以补回本币流动性。是否冲销、冲销到什么程度，需要查实际操作，不能由汇率走势倒推出固定答案。

冲销后是否还影响汇率？理论上可能有几个渠道：官方交易改变私人部门持有不同币种资产的组合，或传递未来政策意图；也可能在市场不愿接盘时帮助协调交易。若两类资产对市场而言几乎完全可替代，且政策信号没有新信息，持续效果就可能很小。由此可见，讨论广场的效果至少要区分公开协调信号、实际外汇买卖和国内货币政策变化，不能用“央行卖了多少美元”代替全部因果分析。

## 十一、金融开放早已开始：宽松落在变化中的银行体系

日本的金融自由化并不是广场饭店里突然诞生的。日本财务省编纂的政策史记录，1980年12月实施的外汇法改革以原则上开放、必要时最低限度限制为方向；1984年4月取消远期外汇交易的实需原则，6月取消部分外汇掉期限制，并放宽居民企业在离岸日元债券市场融资的条件。这些变化有自身的国内金融发展和美日谈判背景，时间都早于1985年9月。[日本财务省政策史，印刷第85、131—132页](https://www.mof.go.jp/english/pri/publication/policy_1972-1990/Full_edition1972-1990.pdf)

“实需原则”要求某些外汇远期交易有实际贸易等需要作依据。放松后，客户和金融机构可以更自由地安排头寸与风险管理，市场更容易连接；这会增加选择，也要求更好地识别风险。“离岸日元”则是日本境外市场上的日元资金，不是欧元，也不表示日元只能在欧洲交易。企业取得另一条融资渠道后，可以比较境内贷款与境外发债成本。

对大型优质企业，这种选择可能降低对银行贷款的依赖。对过去以这些企业为稳定客户的银行，则意味着原有业务和利润空间受到竞争。银行可以改进服务、调整成本，也可能寻找房地产、中小企业或其他更高收益贷款。金融开放本身不等于这些新贷款一定坏，但银行原有的客户筛选经验未必适用于所有新领域，监管与内部风控也未必同步完善。

这里存在一条与广场相互作用、但不由广场单独造成的路径：金融工具和融资渠道变化，改变谁能够绕开旧限制；货币宽松降低融资成本；资产价格上涨改善账面抵押；银行竞争再影响资金流向。只讲低利率，无法解释为什么同样便宜的资金有时支持生产设备、有时追逐既有土地。只讲自由化，也无法解释为什么在特定利率、预期和监管环境下风险积累特别快。

理解下一章的关键，就是保留这一中间层。汇率协议影响宏观环境，银行和企业的资产负债表决定资金怎样使用，土地与证券制度又影响预期如何放大。因果链条的每一环都有可观察的合同、政策和行为，不能跳过它们直接从1985年的声明跳到1990年代的坏账。

## 十二、为什么2.5%维持那么久：低物价与资产繁荣的冲突

日本官方贴现率降至2.5%后，一直保持到1989年5月。这段持续时间，与最初为应对升值而降息，是两个不同问题。白川方明2011年的回顾提供了一个有用对照：西德也曾把官方贴现率降到2.5%，但从1987年12月到1988年7月便结束这一水平；日本维持得更久。他同时指出日本1986—1988年消费者物价涨幅平均仅约0.5%。[白川方明，全球失衡与经常收支，正文第2部分及注3—4](https://www.boj.or.jp/about/press/koen_2011/ko110218a.htm)

德国并不是完美的对照实验：金融结构、实际经济、财政和汇率约束不同，不能据此算出日本“应该”加息的唯一日期。但它足以提醒我们，参加国际协调没有让所有国家只能维持同一利率、同一期限。解释日本的持续宽松，还需要国内判断和政治条件。

时任日银政策委员植田和男在2000年的回顾中指出，1987年夏经济恢复时，日银曾允许短期市场利率上行，随后10月国际股市大跌又使收紧暂停；1988年政策讨论面对的困难，则包括消费物价仍低、外部要求保持低利率，以及对日本经济前景的乐观评价。这里是后来央行人士对历史约束的解释，不应自动当成决策失误已得到完全免责的结论。[植田和男2000年5月5日会议讲话，1987—1988年讨论](https://www2.boj.or.jp/archive/en/announcements/press/koen_2000/ko0005a.htm)

为什么低CPI会使决定更难？通常的反通胀理由是工资、商品和服务广泛涨价；如果进口成本因升值下降，消费物价又平稳，收紧政策的直接理由就不如第18章美国大通胀时期醒目。与此同时，土地和股票买卖价格可能持续上涨，借款人根据涨价增加杠杆。央行面临的问题变成：是否应为了尚未表现为消费物价上涨的金融风险，提高全社会融资成本？

如果只等CPI明显上涨，信用和抵押风险可能已经积累；如果根据每次股票上涨都提前猛烈收紧，又可能把合理的生产率或盈利改善误判成泡沫。除了总量利率，还可以考虑贷款集中度、抵押估值、资本缓冲和金融机构监督，但这些措施需要掌握具体风险并愿意限制正在获利的参与者。低物价并不证明没有金融失衡，资产价格上涨也不自动给出应该加息几个百分点的答案。

因此，对这段政策的合理追问是：当时已能看见哪些借贷和估值信息，哪些风险被低估，是否有更适合的工具，维持宽松的解释是否在经济恢复后仍成立。国际协调和外部压力属于约束，但国内机构如何评估与执行仍需承担解释责任。这个问题将从下一章的实际银行信贷和资产市场证据继续展开。

## 十三、怎样检验“广场导致日本失落”的说法

可以先把它拆成三个不同命题。第一，广场是否改变汇率预期和美元走势？第二，应对升值的日本政策是否加大了后来资产繁荣？第三，泡沫破裂为何演变成长期修复？前一个命题即使成立，也不会自动证明后两个全部由同一协议决定。

在第一个问题上，Frankel对广场的评价较为积极，强调国际政策协调及其缓解贸易保护压力的意义；他同时反对把随后日本长期困难直接归因于1985年促升值，因为在1990年代衰退之前，已经经过1987—1989年的资产繁荣和支持美元的政策阶段。[Frankel，《广场协议三十年后》，开头评价及“Did the Plaza Accord Sabotage Japan?”部分](https://frankel.scholars.harvard.edu/file_url/1228)

Taylor则更强调冲销干预难以持续决定汇率、会前美元已经下降，以及真正货币政策变化的作用。他对日本后来过度宽松的评价，与对外汇市场买卖效果的怀疑，是可以同时成立的：即使一笔冲销交易本身影响有限，国际协调仍可能通过影响国内利率选择而产生重要后果。[Taylor，第2—5页对干预与国内货币政策的区分](https://kingcenter.stanford.edu/sites/g/files/sbiybj16611/files/media/file/559wp_0.pdf)

两种观点不能只按“支持协议”与“反对协议”归类。研究对象有时不同：短期公告反应、几个月汇率趋势、几年贸易调整和十年金融损失，本来就不是同一个结果。干预又往往是在市场压力特别大时发生，简单比较“有干预的日子”和“没干预的日子”可能把政策应对的冲击当成政策效果；反过来，看见会议之后方向符合意愿，也不能排除利差、增长和市场预期本来就在改变。

第二个命题需要检查传导。我们已经看到升值压缩部分出口利润、政策先支持日元后降息、1987年后还要求汇率稳定，金融渠道也在变化。由此可以提出“汇率顾虑促成宽松、宽松与金融制度共同助长泡沫”的解释。但要证明它的具体强弱，还需下一章的贷款部门分布、土地与股票价格、抵押制度和监管时序；不能把一条可能成立的机制当成已经量化的全部原因。

第三个命题更远。即使能确定泡沫发生的政策原因，也仍要解释坏账确认、银行资本、企业债务、财政选择以及后来新冲击。相同资产跌幅在不同资本和处置制度下，可能形成不同长度的修复。把长期停滞直接标为一份1985年协议的效果，会使1990年代的实际决策者、制度和可选路径全部从历史中消失。

本章据此形成一个有限而具体的判断：广场是国际汇率协调的重要节点，确实改变了日本政策面对的环境；它没有签署一份日本必须制造资产泡沫的合同。日本面对真实的升值冲击，也拥有需要独立评价的政策选择。要继续理解为什么融资最终把土地和股票价格推向危险状态，下一章必须进入金融机构和企业的账本。

## 理解与迁移题

### 1. 美元在广场会议前已开始下降，能否因此证明协议毫无作用？

**参考答案：** 不能。它能否定“全部下降始于会议”，但公告可能加快或强化原趋势。需要区分短期信息效应、实际干预与其他政策变化，并构造没有协调时的反事实；单看先后顺序既不能证明全部有效，也不能证明完全无效。

### 2. 每美元从240日元变成160日元，美元与日元各变化多少？固定1万美元出口收入怎样变化？

**参考答案：** 美元的日元价格下降三分之一，日元的美元价值上升50%。出口收入从240万降至160万日元，减少80万。企业净损失还取决于进口投入、套期保值、美元提价能力及成本调整，不能只把收入变动当利润变动。

### 3. 为什么不能把1985年秋市场利率上升与1986年官方贴现率下降说成资料冲突？

**参考答案：** 时间与工具都不同。初期市场操作曾支持较高短期利率以巩固日元升值，之后政策转向缓解国内压力。票据市场利率和央行贴现率也不是同一个价格。需要先统一日期和工具，再判断政策方向。

### 4. 当局买入1亿美元、支付200亿日元，同时卖出200亿日元国内证券，为什么不能只写“印了200亿日元”？

**参考答案：** 前一交易增加本币结算余额，后一交易吸收同额余额，合计可不增加净流动性，但官方资产构成改变。这是冲销的教学例子。外汇信号、资产供给与未来政策预期仍可能影响市场，然而银行体系可用本币的净变化不能只算第一笔。

### 5. 1987年方案超过6万亿日元，而中央追加预算新增支出约2.2万亿，是否说明其余资金全部不存在？

**参考答案：** 不说明。方案还包括税收、地方投资、财政投融资和其他渠道，也可能包含时点提前。应分别核对各项授权、融资和执行，避免把标题金额当全部中央现金支出。是否真正增加需求，还要与没有方案的基准路径比较。

### 6. 西德也参加协调却较早结束2.5%贴现率水平，这个比较能证明和不能证明什么？

**参考答案：** 它说明国际协议没有机械规定所有国家同一期限维持同一利率，日本后续选择需要单独解释。它不能证明日本照抄德国就一定没有泡沫，因为金融结构、需求和风险暴露不同。比较能检验“完全别无选择”的强命题，不能直接给出日本最佳政策日期。
