# 战后经济与金融史

从制度建立、矛盾积累到政策转向与危机，连续解释国际与中国经济史。全书十篇六十章已完成编写与本轮审阅，正文约66.8万汉字（不含章末练习与来源账）。验收证据见[编写与审阅进度](https://github.com/fangpings/economic-history/blob/main/reviews/progress.md)。

## 阅读方式

每章讲清当时的问题、政策选择与执行、风险如何传递、谁承担成本以及后续变化。国际与中国双线按时代衔接，必要时回到同一历史阶段观察另一条线。较近事件明确截止日，不以事后结果代替当时信息。
